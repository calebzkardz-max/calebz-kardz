📁 Folder Mpya (SMS)

Folder haihitaji tarehe wala venue - ni kwa ajili ya kuhifadhi contacts na kutuma SMS pekee (mfano: michango), hata kama event bado haijatengenezwa.

🗑️ Futa Folder

Huna Folder yoyote iliyotengenezwa bado. Tumia "📁 + Folder Mpya" kwanza.

Orodha hii inaonyesha Folders pekee (za SMS/michango) - Events halisi hazionyeshwi hapa kwa sababu wageni wake ni rekodi ile ile inayotumika kwenye "Tuma Mialiko" (Invitations), hivyo kuwafuta hapa kungeathiri mialiko. Kufuta Folder hakuathiri Invitations kwa vyovyote.
